Colophon

This site is hand-written HTML and CSS — no frameworks, no trackers, no cookies. It is set in ETbb, Michael Sharpe's extension of the ET Book family; the colors come from my talk slides. The squiggle in the navigation is a damped sinusoid — a black hole's ringdown — and it doesn't like being poked. The favicon is a Penrose diagram that spells my initials.
